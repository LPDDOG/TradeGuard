# TradeGuard 第六阶段验收记录

日期：2026-10-22。范围：本地静态版本 V0.6；所有测试资料均为虚构。

## 已修复的问题

- 金额验证从浮点容差改为十进制格式检查，拒绝 `0.0000000001` 等超出两位小数的输入，也拒绝十六进制与科学计数法文本；合法分币保持不变。
- 保存前检查浏览器存储是否已被其他页面更新，发现旧页面时拒绝新增、编辑、删除或导入覆盖。用户得到提示，并保留表单输入。刷新后可继续操作。恢复演示数据仍是明确确认后的替换操作。
- 键盘“跳转至主要内容”只移动焦点，不再改变路由并误切回首页；手机菜单名称与展开状态同步。
- 手机端按钮和操作链接至少 44px 高；表单文字增至 16px；长客户名称、地区和备注换行；表格支持键盘聚焦与横向滚动提示；弹窗限制在视口内并可滚动。
- 面向访问者的提示改为实际的数据保存方式，不再以开发阶段作为主要产品提示。

- **真实 GitHub Pages 发布**：尚未上传与发布。本地子路径验证不等于线上部署成功。
- **极端并发及大规模数据性能**：旧页面检查用于避免常见顺序覆盖，不提供数据库事务或多设备同步能力。未完成 10000 笔订单的性能验收；建议作品集展示使用内置演示规模。
