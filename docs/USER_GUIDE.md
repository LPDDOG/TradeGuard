# TradeGuard 使用指南

所有示例均为虚构数据，请勿输入真实客户资料。网站不需要注册或登录。

## 第一次体验

打开根目录 index.html，或未来发布后的正式网址。首页自动展示 18 条虚构订单的统计。手机点击左上角菜单切换页面。

推荐先在“订单管理”查看一笔订单的评估，再编辑付款方式，观察分数与看板的变化。没有自动交易批准或拒绝流程，最终判断仍需人工复核。

## 录入与管理

“新建风险评估”中除备注外均须填写；合作年限 0 表示首次合作。创建日期限 1900 年起至今天，金额允许 0，最多两位小数。点击“保存并查看评估”后，订单才写入本浏览器。

订单页支持搜索客户、地区、编号或备注，再组合付款方式与地区筛选。手机表格可左右滑动，操作按钮在右侧。删除前会出现确认窗口。

如果提示“其他页面更新”，本次保存没有覆盖新数据。先记录当前输入，再刷新并重试。数据不会在多个设备或浏览器之间同步。

## 图表

首页图形支持鼠标悬停或轻触查看数值，每张图下方有数据表。风险图例可切换显示；固定数量和数据表仍反映全部订单。趋势年份只影响月度图，不影响其他统计。没有订单的月份记为零。

## CSV 备份与导入

在订单页点击“导出全部 CSV”，下载全部原始订单信息。搜索、筛选不会限制导出范围，导出不包含缓存评分。

“下载 CSV 模板”包含一条可替换的虚构订单。保留全部列名及顺序，另存为 UTF-8 CSV：

| 列 | 约定 |
| --- | --- |
| 订单编号 | 可留空自动生成；提供时只能含英文字母、数字、连字符，最多 80 个字符，不可重复 |
| 客户名称 | 1—100 个字符 |
| 国家或地区 | 1—60 个字符，不影响评分 |
| 订单金额（美元） | 普通数字，不加币种、千位逗号，最多两位小数 |
| 付款方式 | 100% T/T 预付、30% T/T 预付、L/C、D/P、O/A 之一 |
| 合作年限 | 0—200 的整数 |
| 历史逾期次数 | 0—100000 的整数 |
| 订单创建日期 | YYYY-MM-DD，不晚于今天 |
| 备注 | 可空，最多 1000 个字符 |

文件以英文逗号分隔；含逗号、双引号或换行的字段需符合 CSV 双引号转义格式。建议在电子表格中另存为“CSV UTF-8”，避免手写转义。

选择文件后会先验证，再展示待导入数量、金额和首笔客户。点击“确认导入”才追加保存；取消、格式错误或存储失败不会部分写入。每次最多 2 MB、2000 笔，总订单不超过 10000 笔。

重复编号不会覆盖已有订单。将刚导出的文件直接导回同一批数据会被拒绝；确需创建新订单时，可把对应编号留空。文本中的公式符号会在导出时加单引号保护，再由本平台导入时还原；外部软件仍可能改变单元格格式，请核对数据。

## 恢复演示数据

该操作在确认后用 18 条演示订单替换全部当前订单，无法撤销。建议先导出 CSV 备份。它也能显式替换损坏的本地存储；如果浏览器禁止存储，恢复仍会失败并提示。

## 报告打印与保存 PDF

打开单笔订单的“查看评估”，点击“打印 / 保存 PDF”。普通 Chrome 或 Edge 的打印窗口中可选择“另存为 PDF”，建议 A4 并关闭浏览器页眉页脚。也可用浏览器打印快捷键打开当前报告。

实际 PDF 成品尚未通过验收：内置浏览器调用打印窗口超时。使用普通浏览器时应检查所有页面是否包含客户信息、总分、四项评分、主要因素、复核建议、生成日期及用途声明。当前截图是屏幕界面，不是 PDF 证据。

## 数据丢失或无法保存

先确认是否使用原浏览器和原访问地址；本地文件、预览地址、GitHub Pages 地址拥有各自独立的存储。隐私模式、清除网站数据或浏览器空间不足都可能影响保存。

读取失败时系统不会自动覆盖原存储，写入失败也不会显示成功。当前不具备云端备份与账号同步能力，CSV 是可用的迁移方式。
